# Intune Compliance Policy

## Policy Name

- Windows 10/11 Compliance Policy

## Compliance Settings

- Require BitLocker: Enabled
- Require Secure Boot: Enabled
- Require Firewall: Enabled
- Require Antivirus: Enabled
- Require Password: Enabled
- Require Code Integrity: Enabled

## Purpose

- Improve overall security and compliance for managed Windows endpoints.
